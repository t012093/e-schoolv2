# 体調管理機能 UI設計書

## 概要
ユーザーの日々の体調や生活習慣を記録し、AIが分析・アドバイスを提供する機能

## 主要コンポーネント

### 1. 初回ログイン時のヘルスチェック（モーダル/ポップアップ）
**場所**: ログイン後のダッシュボード（`src/app/page.tsx`）に表示

#### UI要素
- **ヘルスチェックモーダル** (`HealthCheckModal.tsx`)
  - 時間: 表示時刻、最終記録からの経過時間
  - 基本項目（選択式）:
    - 体調: 😊とても良い / 😐普通 / 😔少し悪い / 😷悪い
    - 睡眠時間: スライダー（3-12時間）
    - 睡眠の質: ⭐1-5段階評価
    - ストレスレベル: 🟢低い / 🟡普通 / 🔴高い
    - 運動: ✅した / ❌しなかった（種類・時間を追加入力可）
  - オプション項目:
    - 気分: 複数選択タグ（元気、疲れた、集中できる、眠い、等）
    - 食事: 朝/昼/夜のチェックボックス
    - 水分摂取: グラス数カウンター
  - 自由記述メモ欄
  - 「記録する」「後で」ボタン

### 2. 体調管理ダッシュボード（新規ページ）
**ルート**: `/health` 
**ファイル**: `src/app/health/page.tsx`
**メニュー**: サイドバーに「体調管理」アイコン（Heart/Activity）追加

### 3. AIアドバイスセクション
**場所**: 体調管理ダッシュボードの下部または右サイドバー

#### コンポーネント構成
- **AIインサイトカード** (`HealthInsights.tsx`)
  - 週間/月間サマリー
  - パターン分析（例：「火曜日は疲れやすい傾向」）
  - 改善提案（例：「睡眠時間を30分増やすことを推奨」）
  - 注意アラート（例：「3日連続でストレス高め」）
  
- **パーソナライズされた推奨事項**
  - 学習スケジュール調整提案
  - 休憩タイミング提案
  - 生活習慣改善アドバイス

### 4. 月間レポート（モーダル/別ページ）
**アクセス**: 体調管理ダッシュボードの「月間レポート」ボタン

#### 表示内容
- 月間統計サマリー
- カレンダービュー（ヒートマップ）
- トップ3の改善ポイント
- 前月比較
- PDF出力機能

## デザイン仕様

### カラーパレット
- 体調良好: `#10B981` (green-500)
- 体調普通: `#F59E0B` (amber-500)
- 体調不良: `#EF4444` (red-500)
- 背景: 既存のグレースケール使用
- アクセント: 既存のブルー/パープル使用

### アイコン
- Lucide Reactアイコン使用:
  - Heart (体調)
  - Moon (睡眠)
  - Brain (ストレス)
  - Activity (運動)
  - TrendingUp/Down (トレンド)
  - Calendar (月間ビュー)

### レスポンシブ対応
- モバイル: カード縦積み、グラフ簡略化
- タブレット: 2カラムレイアウト
- デスクトップ: 3カラムレイアウト、サイドバー表示

## インタラクション

### データ入力フロー
1. ログイン → HealthCheckModal自動表示（前回から12時間以上経過時）
2. 簡単選択 → 詳細入力（オプション） → 確認
3. 「後で」選択時は、ヘッダーに通知バッジ表示

### データ表示
- リアルタイム更新（入力後即座に反映）
- スムーズなアニメーション（Framer Motion使用検討）
- ツールチップでの詳細表示
