# 📱 パーソナルAI学習プラットフォーム - モバイルUI サンプル

Duolingoスタイルの直感的でミニマルなモバイル学習アプリUIデザイン

## 🎨 デザインコンセプト

- **ミニマリズム**: 情報量を極限まで削ぎ落とし、1画面1目的
- **直感的操作**: タップ、スワイプ、ドラッグのみで完結
- **視覚的魅力**: 明るいグラデーション、ポップな色使い
- **ゲーミフィケーション**: バッジ、レベル、進捗の可視化

## 🎨 デザインシステム

### カラーパレット
- **メイン**: `#4ADE80` (Green-400)
- **アクセント**: `#60A5FA` (Blue-400)
- **グラデーション**: Green → Blue
- **背景**: 白 + 薄いグラデーション（Green/Blue/Purple）

### タイポグラフィ
- **見出し**: 2xl - 3xl (Bold)
- **本文**: Base (Medium)
- **補足**: xs - sm (Regular)

### スペーシング
- **余白**: 広め（6 = 1.5rem, 8 = 2rem）
- **カード間隔**: 3-4 (0.75rem - 1rem)
- **パディング**: 4-6 (1rem - 1.5rem)

### コンポーネントスタイル
- **角丸**: 2xl - 3xl (16px - 24px)
- **影**: sm - lg（控えめ）
- **ボーダー**: 細め（1-2px）
- **トランジション**: スムーズ（200-500ms）

## 🚀 特徴的なUI要素

### インタラクション
- **アクティブ状態**: `active:scale-95`（タップ時に縮小）
- **ホバー効果**: 色の変化、影の強調
- **スワイプ対応**: 横方向のコンテンツ切り替え
- **プログレス**: 円形 & バー型の進捗表示

### アニメーション
- `animate-bounce`: 絵文字やアイコン
- `animate-pulse`: 背景の波紋効果
- `transition-all`: スムーズな状態変化
- グラデーションの動的変化

## 📱 レスポンシブ対応

- iPhone サイズを想定（max-w-md = 448px）
- セーフエリア対応
- タッチフレンドリーなボタンサイズ（最小 44x44px）

## 🎯 使用方法

このUIサンプルは、既存のcapy-uiプロジェクトから独立したディレクトリです。

### 統合方法

1. **スタンドアロンとして使用**
   ```bash
   # このディレクトリを別プロジェクトとしてセットアップ
   cd mobile-ui-sample
   npm install
   npm run dev
   ```

2. **既存プロジェクトに統合**
   - `src/screens/*` を既存のNext.jsプロジェクトにコピー
   - `src/components/MobileLayout.tsx` を追加
   - ルーティングを設定
